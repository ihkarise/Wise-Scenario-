# WiseCases

**Think. Diagnose. Learn.** A progressive, scenario-based reasoning engine for medical, homeopathy and clinical education.

A learner reads a case and answers. Each wrong answer costs a life and reveals the next clue, with new answer options, until they solve the case or run out of lives. Every ending leads to a full reasoning review.
